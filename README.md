# Otimização de tanque cilíndrico

Trabalho de Modelagem Computacional (UERJ/IPRJ).

Minimiza o custo de um tanque cilíndrico com volume mínimo de 500 m³,
usando método do gradiente, diferenças finitas e função de penalização.

## Como rodar

    pip install matplotlib
    python codigo.py

O programa imprime a tabela de resultados e gera os gráficos
`convergencia_custo.png`, `trajetoria.png` e `curvas_nivel.png`.
